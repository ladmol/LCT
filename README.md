# Vehicle Re-Identification (Re-ID) — ЛЦТ 2026, задача Falcon Tech

Сервис, формирующий устойчивый «цифровой отпечаток» автомобиля по визуальным признакам (тип кузова, марка/модель, цвет, геометрия, повреждения, наклейки, диски, тонировка и др.), не зависящий от государственного регистрационного номера. Позволяет сопоставлять один и тот же автомобиль на разных камерах/ракурсах/в разное время и предлагать вероятный номер для эпизодов, где он не читается, если для того же кластера событий номер был распознан ранее.

## Техническое задание

Полный текст: [`7. Фалькон Тех.pdf`](<7. Фалькон Тех.pdf>). Ключевые моменты:

- **Задача — open-set image retrieval**: дана галерея (фото с известным `vehicle_id`) и запрос (фото, чью идентичность нужно установить); `vehicle_id` train/test **не пересекаются** — модель должна обобщаться на не виденные ранее машины, а не классифицировать по фиксированному списку.
- **BBox выдаётся заранее** организаторами (в `train.csv`/`test.csv`, вместе с `image_id`/`vehicle_id`) — **детекция ТС, распознавание номеров и трекинг в задачу не входят**.
- **Номера и лица на всех фото уже размыты** организаторами; использование любых признаков номерного знака для идентификации — **основание для дисквалификации**.
- Пайплайн: приём (фото + BBox) → извлечение эмбеддинга фиксированной размерности (+ опционально атрибуты) → векторный поиск по галерее (косинус/L2) → ранжированный топ-N кандидатов **или пустой ответ («режим отказа»)**, если уверенного совпадения нет — порог отказа выбирает и обосновывает команда.
- **Метрика**: mAP (основная, 45% оценки) только по кросс-камерным совпадениям (в пределах одной камеры — не считается); доп. метрики — Rank-1/Rank-5, и отдельно F1/TNR/mINP для режима отказа (10% оценки).
- **Архитектура**: микросервисы, backend на Python/C++/Rust под Linux, векторная БД (PostgreSQL+pgvector/FAISS/Milvus), API через OpenAPI/Swagger, тонкий веб-клиент, всё — в Docker (`Dockerfile` + `docker-compose.yml`, запуск одной командой).
- **Инференс должен работать без доступа в интернет** — все веса поставляются в составе решения. Суммарный размер весов моделей — **не более 2 ГБ**.
- **Артефакты сдачи**: `submission.csv` (топ-10 кандидатов на запрос), `embeddings.npy` (эмбеддинги всей тестовой выборки), `candidates.csv` (результат режима отказа), код+Dockerfile+docker-compose+файл зависимостей, презентация (PDF/PPTX), Readme с полным списком внешних библиотек/весов/датасетов и версий.
- Внешние предобученные веса и открытые датасеты — разрешены и приветствуются, но обязаны быть перечислены в Readme; **закрытые/невоспроизводимые источники — недопустимы**.

## Коротко о решении

```
Камера/ПАК --POST /extract (push)--> Детектор (YOLOv8) → Кроп → Re-ID эмбеддер + Атрибутные головы
    → Fingerprint-вектор → сохранение (Qdrant/FAISS + PostgreSQL) → автопоиск похожих → cluster_id

Оператор --POST /search (read-only)--> тот же пайплайн → ANN-поиск → Re-ranking
    → топ-N кандидатов + подсказка номера, если известен для кластера → Demo UI (React/Vite)
```

Сервис не тянет видеопоток с камер — только принимает уже готовые снимки по HTTP push. Полная диаграмма и контракты API — в [docs/architecture.md](docs/architecture.md).

## Структура репозитория

- `backend/` — FastAPI-сервис (Трек B), пакеты через [uv](https://github.com/astral-sh/uv)
- `ml/` — детектор, Re-ID модель, атрибуты, метрики (Трек A), пакеты через uv. Есть заготовка под OCR номера, но это вне ядра хакатона — делается позже
- `frontend/` — demo-UI, React + TS (Vite), пакеты через [pnpm](https://pnpm.io/)
- `docs/` — архитектура, стек, план разработки
- `data/` — датасеты и веса моделей (в git не попадают, см. `.gitignore`)
- `docker-compose.yml` — Qdrant + PostgreSQL для локальной разработки

## Датасеты

- **CityFlowV2-ReID** (`data/raw/cityflow/`) — 85 058 фото, 880 identity автомобилей (440 train / 440 test), 46 камер реального городского трафика. Используется как рабочий Re-ID датасет (официальный VeRi-776 доступен только по запросу на почту, поэтому стартуем отсюда). Источник: [AI City Challenge 2021, Track 2 — City-Scale Multi-Camera Vehicle Re-Identification](http://www.aicitychallenge.org/2021-track2-download/) (официальный сайт: [aicitychallenge.org](https://www.aicitychallenge.org/)).
