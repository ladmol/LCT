# Vehicle Re-Identification (Re-ID) — ЛЦТ 2026, задача Falcon Tech

Сервис, формирующий устойчивый «цифровой отпечаток» автомобиля по визуальным признакам (тип кузова, марка/модель, цвет, геометрия, повреждения, наклейки, диски, тонировка и др.), не зависящий от государственного регистрационного номера. Позволяет сопоставлять один и тот же автомобиль на разных камерах/ракурсах/в разное время и предлагать вероятный номер для эпизодов, где он не читается, если для того же кластера событий номер был распознан ранее.

## Коротко о решении

```
Кадр → Детектор ТС (YOLOv8) → Кроп → Re-ID эмбеддер (FastReID: OSNet/ResNet50/TransReID)
    + Атрибутные головы (цвет/тип кузова) → Fingerprint-вектор
    → Vector DB (Qdrant/FAISS) → ANN-поиск → Re-ranking → Кандидаты
    → Backend API (FastAPI) → Demo UI (Streamlit/Gradio)
```

Полная диаграмма и детали — в [docs/architecture.md](docs/architecture.md).
