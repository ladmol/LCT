# Результаты экспериментов Vehicle Re-ID

Все строки используют одно разделение идентичностей `seed=42`. Dev служит для
выбора эпохи, режима инференса, веса ансамбля и порога. Holdout не участвует в
выборе. Значения относятся к локальному cross-camera протоколу.

Ансамбль использует равные веса. Конфигурация `flip + flip, 0.5/0.5` выбрана по
максимальному dev mAP среди 36 комбинаций режимов и весов от 0,1 до 0,9.
FP16 deployment-веса меняют holdout mAP менее чем на `0,0001` и сохраняют
Rank-1/Rank-5, поэтому именно они входят в репозиторий.

## Несколько кадров одной камеры

Этот режим соответствует онлайн-сценарию с коротким треком. Он не применяется к
официальному single-image test и не меняет конкурсные `submission.csv` и
`embeddings.npy`.

| Агрегация до поиска | Holdout mAP | Holdout R1 | Holdout R5 |
| --- | ---: | ---: | ---: |
| Первый кадр трека | 0,583 | 0,458 | 0,731 |
| **Среднее до 3 кадров** | **0,644** | **0,531** | **0,777** |
| Medoid | 0,592 | 0,465 | 0,754 |
| Среднее с весом качества | 0,644 | 0,531 | 0,777 |

Для среднего вектора консервативный режим, откалиброванный только на dev,
принимает `19,5%` holdout-запросов: precision `0,742`, TNR неизвестных `0,931`.
Строгий режим принимает `15,4%`: precision `0,755`, TNR `0,966`. Для остальных
запросов система возвращает отказ и оставляет решение оператору.

## Что не сработало

- 26 проверенных внешних фото восьми машин недостаточны: mAP изменился с
  `0.309` до `0.308`.
- Сильные affine, color jitter, grayscale и random erasing вместе ухудшили
  holdout mAP с `0.429` до `0.382`.
- Отдельный multi-crop широких BBox не улучшил общие метрики и ухудшил широкий
  срез ConvNeXt.
- Flip TTA почти бесполезен для одиночного ConvNeXt, но помогает сочетанию
  ConvNeXt и ResNet50.
- Продолжение ConvNeXt улучшило dev, но ухудшило holdout; исходная эпоха оставлена.
- ArcFace с margin `0,2` четыре эпохи подряд не превысил dev mAP исходной модели.
- DINOv2-S/14 с осторожным fine-tune и разными pooling-вариантами остался слабее
  CNN-ансамбля; добавление к ConvNeXt не изменило вывод.

## Внешний набор 5–7 ГБ

Массовый опыт пока не имеет результата: без активной пользовательской сессии
страницы объявлений перенаправляют автоматический клиент на вход. В таблицу не
подставлялись оценки с пилота вместо обещанного большого набора. После получения
доступной авторизованной вкладки порядок остаётся таким:

1. собрать исходные фото в игнорируемый каталог с ограничением объёма и
   свободного места;
2. проверить объявления, BBox, закрытие номерных знаков и лиц, а также метки
   атрибутов; номерные знаки не распознавать и не сохранять;
3. зафиксировать список одобренных экземпляров и исключить дубликаты;
4. предобучить те же архитектуры на instance ID и атрибутах;
5. дообучить на конкурсном train;
6. сравнить на неизменном holdout с ConvNeXt и ансамблем.
