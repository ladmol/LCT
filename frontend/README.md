# Demo UI

Интерфейс принимает два JPEG/PNG через выбор файла или drag-and-drop, передаёт
каждый кадр как один BBox в `POST /api/extract` и сравнивает полученные
L2-нормированные признаки по cosine similarity. Решение показывается относительно
откалиброванного порога `0.5051871538`; отображаемый score не является вероятностью.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Vite проксирует `/api` на `http://127.0.0.1:8000`.
