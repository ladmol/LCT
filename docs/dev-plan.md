# Состояние и дальнейший план

## Готово к сдаче

- [x] единый протокол train/dev/holdout без утечки identity;
- [x] ансамбль ConvNeXt Tiny + ResNet50 и flip TTA;
- [x] подбор порога отказа только по dev;
- [x] submission 1110 query × 750 gallery × 2816;
- [x] checkpoint для автономного инференса без интернета;
- [x] реальный FastAPI endpoint и demo UI;
- [x] тесты ML, backend, frontend build и Docker config;
- [x] запрет использования номерных знаков.

## После хакатона

1. Заполнить Qdrant векторами и добавить top-k поиск по cosine.
2. Объединять до трёх кадров одного tracklet средним вектором.
3. Калибровать порог отказа на изображениях целевых камер.
4. После разметки добавить головы марки, модели и рестайлинга как отдельные
   подсказки, не меняя основной Re-ID вектор.
5. Экспортировать модели в ONNX/TensorRT для меньшей задержки.

Каждая новая версия получает новый `model_version`; старые и новые векторы в
одном индексе не сравниваются.
